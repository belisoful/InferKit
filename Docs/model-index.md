# Model index: classes, configurations, and entry points

One row per implemented model: the class a consumer calls, the network class under it, the
configuration preset or variant that matches the released weights, the name it registers under, and the
base backend that gives it the InferKit contract. The measured parity for each row is in
[model-parity.md](model-parity.md); the subsystems the rows share are itemized there too.

Conventions. A `*Configuration` struct is Swift-only; the `@objc` `*Variant` enum or the `directoryURL:`
factory is the Objective-C knob. The **Copy-and-paste** column is a construction line for the released
weights in Swift and in Objective-C (`url` / `dir` are the local weights or release directory, `error`
an `NSError *`), followed by the other variants' spellings; every `backend(…weightsURL:)` factory also has a
`backend(…repo:weightsPath:revision:cacheDirectoryURL:)` download peer and an asynchronous
`…completionHandler:` peer (ObjC `backendWithRepo:weightsPath:revision:cacheDirectoryURL:error:` and
`…completionHandler:`), and `nil` weights build a randomly initialized network. Every `…DirectoryURL:`
factory likewise has a release-download peer, `DirectoryURL:` replaced by `Repo:revision:cacheDirectoryURL:`
(Swift `…(repo:revision:cacheDirectoryURL:…)`), with its `…completionHandler:` form; a gated repository
reads `NFKHFHub.defaultAccessToken`. Every registered name
also builds through `NFKMLXModelRegistry.backend(named:weightsURL:)` after
`NFKMLXReferenceModels.registerAll()`, or downloads through `NFKMLXHub.backend(named:repo:weightsPath:revision:cacheDirectoryURL:)`.
`tiny` presets exist on most configurations for tests and are not listed. A row marked no public
constructor yet names a model whose networks are at reference parity but whose pipeline or loader is
still internal to the package (reachable by its tests through `@testable import`); the missing public
entry is listed so it is a known gap rather than an implied API.
